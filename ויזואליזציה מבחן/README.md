# ויזואליזציה — איך מתחלק תקציב מבחן התמיכה (איגודים 2026)

**משפך כסף אינטראקטיבי:** רצועה של 100% מתפצלת ל-8 תחומים; לחיצה על תחום "פותחת" אותו לרצועה מלאה של אמות המידה שלו, וכן הלאה — עד כרטיסי הניקוד האטומי (כולל השוואת ניקוד ספורטאי/ספורטאית). רוחב כל מקטע = חלקו האמיתי בכסף, וכל רמה מציגה כמה זה "מכל 100 ₪ תקציב".

## שימוש
פותחים את `index.html` בדאבל-קליק בכל דפדפן. **עובד אופליין** — הכול מוטמע בקובץ אחד (בלי CDN, בלי קבצים נלווים), אפשר לשלוח אותו כמו-שהוא לכל הצוות.

- **חדשים בתחום?** כרטיס "איך זה עובד — שלוש קומות", כפתור **סיור מודרך** שמצלול ומסביר לבד, ומילון מונחים. בתחתית כל כרטיס ניקוד — **סימולטור**: מזיזים נקודות לשלושה איגודים לדוגמה ורואים חי איך הכסף מתחלק ביחס לנקודות (ולמה לנקודה אין ערך קבוע).
- לחיצה על מקטע / צ'יפ — צלילה פנימה. לחיצה חוזרת — סגירה. בכל צלילה מוצגת **שרשרת החישוב** המלאה (למשל: 100 ₪ × 37.85% × 45% = 17.03 ₪).
- שדה "התקציב בפועל" (רשות) — ממיר את כל האחוזים לשקלים אמיתיים.
- ריחוף מציג פירוט: % מהאב, החלק מהתקציב הכולל, והערות.
- צבעים: כחול כהה = ניקוד גברים · תכלת = ניקוד נשים · זהב = נוסחה/נספח.

## קבצים
- `index.html` — הוויזואליזציה (עצמאי לחלוטין; הנתונים מוטמעים בתוכו).
- `data.js` — מקור האמת התיעודי לנתונים. **שימו לב:** עדכון ערכים דורש עדכון גם בבלוק הנתונים שבתוך `index.html` (זהה אחד-לאחד).
- `HANDOFF-context.md` — היסטוריית הפיתוח והאימות מול המקור.
