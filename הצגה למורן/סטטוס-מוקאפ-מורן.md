# מוקאפ אסטרטגי למורן — היכן אנחנו

עדכון: 13/07/2026 · קובץ המוקאפ: `הצגה למורן/מוקאפ-אסטרטגי-מורן.html`

## מה זה
מוקאפ קונספט לדשבורד ניהולי־אסטרטגי למשרד התרבות והספורט (מינהל הספורט), בנוי כ־HTML עצמאי אחד, בעברית ו־RTL, בסגנון העיצוב של דשבורד האיגודים הקיים. המטרה: להמחיש חזון לפגישה עם מורן ולבחון היתכנות מול QuickSight. אלא אם צוין אחרת — הנתונים הם דמה להמחשה.

## הלשוניות (10)
- **תמיכות** — התמיכות שהמשרד מחלק לאיגודים ולאגודות על פי מבחני התמיכה (לא תקציב המשרד עצמו — אין לכך חיבור): חלוקה לפי ייעוד, מגמה, ומקורות מימון.
- **הסתכלות גיאוגרפית** (לשעבר "תיק יישוב" — שונה בהתאם להחלטת הפגישה) — ראייה הוליסטית סביב הרשות (מפת חום, כרטיס יישוב, ספורטאים לפי ענף, טבלת רשויות, תקציב מול השתתפות). *כרגע מוגדרת כמסך מוסתר.*
- **גוף נתמך** — כרטיס ארגון בודד מגיידסטאר / רשם העמותות, עם מדד מרכזי "תלות בתמיכה".
- **ביצועים ומגדר** — ספורטאים, הישגים וראייה מגדרית במבט מאוחד.
- **SLA · תפעול** — זמני טיפול, פניות, ועדת חריגים ועררים (תלוי במערכת הפניות הפנימית).
- **IMPACT ויעילות** — שיעור השתתפות מהאוכלוסייה מול יעד, ויעילות תקציבית.
- **קישורים** — שער ניווט למקורות ולדשבורדים (ב־QuickSight: URL Actions).

### חדש (13/07/2026) — רעיונות הסיעור: 3 לשוניות חדשות + איחודים + העשרות
כל 10 רעיונות הסיעור מומשו. אחרי סבב צמצום חזרתיות — 10 לשוניות (במקום 13), חדשות מסומנות בנקודת זהב:
- **קטלוג התוכניות** ★ (חדשה) — פורטפוליו כל 17 המבחנים: תקציב, גופים, ערך נקודה, קריטריון מוביל + כרטיס "תעדוף ענפים מועדפים". מענה לשאלת ה-Overview. מסתכם ל-₪148.1M — זהה ללשונית "תמיכות".
- **מנוע הניקוד** ★ — **אוחד לתוך "גוף נתמך"** (אותו גוף, אותה שאלה): יעד (Target) וייחוס (Attribution) לכל אחוז — המענה לשאלת ה-38.5% של חובב, כולל חשיפה חוצת-תוכניות. הכדורסל כויל לנתוני הפרופיל האמיתיים: ₪22.5M מתוך ₪58.45M (רשם העמותות) = 38.5%; ג'ודו (39.2%) כדוגמת חריגה.
- **שוויון גיאוגרפי** — **אוחד לתוך "הסתכלות גיאוגרפית"** (המוסתרת) כמבט המדיניות של אותו נושא: תמיכה לנפש מול אשכול, רכיבי הנוסחה, יחס פריפריה/מרכז ×1.70. למפת החום נוסף מצב תצוגה "תמיכה לנפש".
- **מנופי מדיניות והכלה** (חדשה) — 4 רעיונות באחד: מגדר כמכפיל · צנרת דור צעיר · מאמנים ומעטפת (1:56 מול יעד 1:45) · **הכלה ומוגבלות אוחדה לכאן** כמנוף הרביעי (מכפיל ×1.5 מאומת, פרמיה ₪6.8M).
- **עמידות וחירום** (חדשה) — האלטרנטיבה החיובית ל-SLA: שאגת הארי, מיגוניות, מדד התאוששות. סכומי החירום (₪7.1M) תואמים לקטלוג. נשמרה נפרדת מ-SLA כדי לא לקשור אותה להחלטת "להוריד את ה-SLA" אם תתקבל.

**העשרות בלשוניות הקיימות (רק עם מקור):** תמיכות — "ניקוד מול תיקונים" + קישור לקטלוג · הסתכלות גיאוגרפית — תמיכה לנפש וצפי-מול-בפועל בכרטיס היישוב · גוף נתמך — אריח תמיכות חירום + יעד ענפי ליד התלות · ביצועים — "הישגים לפי דירוג ומגדר" (מסתכם ל-1,284) + פרמיית נשים ב-Tooltip · IMPACT — KPI יחס פריפריה · קישורים — אריחי ניווט ללשוניות החדשות ולמדד הפריפריאליות של הלמ"ס. **דילגנו על העשרות SLA** — הפגישה קבעה שאין מספיק דאטה (6 פניות בשנה).

**ערוצים שאינם מבחנים במנוע הניקוד:** בעקבות "סוגי הבקשה" בתיק יישוב (3א / רכש / תאגיד / אחר) נוסף למנוע בלוק "תקנות וערוצים שאינם מבחני תמיכה" — ללא ניקוד, מחוץ ל-₪148.1M ומחוץ ליעד התלות — ו-KPI שלישי "חשיפה כוללת מול המשרד" (כדורסל: 38.5% מבחנים ← 40.5% כולל רכש/אחר; ג'ודו: ללא ערוצים נוספים). הדונאט מציג אותם באפור לצד המבחנים בכחול.

**מיפוי מול דשבורד "תיק יישוב" (פרודקשן):** נוסף אריח קישור לדשבורד הקיים (הראשון ברשימה), ו"הסתכלות גיאוגרפית" מוצגת כאבולוציה שלו. תרשימים שכבר קיימים שם סומנו בתג ירוק "קיים בתיק יישוב" + הערת מה-נוסף-כאן: מגמת התמיכות (= "תקציב שאושר לפי שנים"), תקציב לפי מבחן (= "תקציב לפי תקנה > מרכז קרנות/רצועה"), טבלת הרשויות (= "נתוני הלמ"ס" + "תקציב שאושר לפי מחוז > רשות"), כרטיס היישוב (= פרופיל הרשות ב"מסמך לפני סיור שר"). המפה, הסקאטר, השוויון הגיאוגרפי, המנוע והקטלוג — אין להם מקבילה שם.

**החלטות סקירה (13/07 ערב):** ירד מבט "עומס תפעולי — עובדים מול איגודים" (מצבת העובדים קטנה מכדי שהמדד יהיה משמעותי; הפילטר שונה ל"צוות מטפל"). ירד תרשים "יעילות לפי תחום — ₪ למשתתף" (מכנה לא מוגדר). הוגדרה "תפוקה" במפורש בלשונית IMPACT: כל מבחן מגדיר את התפוקה שלו באמות המידה שלו, וערך הנקודה = המחיר ליחידה; בלשונית מוצגים רק מדדים עם מכנה מוגדר (₪ לספורטאי רשום · ₪ למדליה).

**תיקוני מקורות (13/07):** "נוסחת 70/30" של סל הספורט לא נמצאה באף מקור רשמי — הוחלף ל"אשכול חברתי-כלכלי + פריפריאליות (משקלים באימות)" עם תג. "מכפיל נשים ×1.5" תוקן ל-**+30%** לפי מבחן האיגודים (ה-PDF שבתיקייה); מכפיל ×1.5 נכון להכלה (מאומת). ערך היעד הענפי (32%) מסומן "בבדיקת טובה מול מורן". כל הנתונים דמה, עקביים בין המסכים.

## מצב הנתונים — מה אמיתי ומה ממתין
עברנו אודיט היתכנות, בדגש על כרטיס "גוף נתמך". חלוקה לפי מקור:

**אמיתי, זמין עכשיו דרך API רשמי (מאגר רשם העמותות הפתוח · data.gov.il):**
הכנסות (מחזור), שנת דיווח כספי אחרון, מספר עובדים, מתנדבים, חברי עמותה, סטטוס, סיווג, כתובת, מטרות — וכן תרומות מישות מדינית זרה (משאב נפרד). זהו API אמיתי (CKAN), לא גרידה, ולא דורש הרשאות. הערה: הנתונים הם תמונת מצב של שנת הדיווח האחרונה בלבד (לא רב-שנתי), וסך ההוצאות מאוכלס חלקית בין עמותות.

**זמין דרך גיידסטאר API (דורש חשבון) — מסומן "להמחשה" עד לחיבור:**
מקבל תמיכות ממשלתיות (כן/לא), מתן שירותים למשרדי ממשלה, ניהול תקין, אישור סעיף 46, שנת גירעון אחרונה.

**נתון פנימי של המשרד — מסומן "לדוגמה":**
סכום התמיכה שאנחנו מחלקים לגוף, ומדד "תלות בתמיכה" (= התמיכה שלנו ÷ הכנסות העמותה).

**קיים רק בדוח הכספי (PDF) — לא זמין בשום API רשמי:**
פילוח ההכנסות לפי מקור (תרומות פרטיות / שירותים / דמי חבר כסכומים נפרדים), פירוט ההוצאות, וסדרות רב-שנתיות של הכנסות. לכן:
- "מקורות מימון" מוצג כפילוח 3-דרכי רשמי בלבד: תמיכת המשרד + תרומות מדינה זרה + יתר עצמי. פירוק ה"יתר" ממתין ל־PDF.
- הגרפים שדורשים היסטוריה רב-שנתית או פילוח פנימי ("יציבות תקציבית", "מחזור לאורך השנים") מסומנים בתג **"דורש דוח כספי · צבירת נתונים"**.

עקרון מנחה: אף גרף לא מבטיח נתונים שאין לנו. כל שדה נושא ייחוס מקור.

## היתכנות QuickSight
כ־95% מהוויזואלים ילידיים ל־QuickSight (KPI, עמודות/מוערם/מקובץ, קו, Combo דו-צירי, Gauge, Scatter/Bubble, Pivot עם צביעת חום, טבלאות). מפת החום נבנית כ־Custom Shape Map מ־GeoJSON של מחוזות ישראל. הרכיבים הלא-ילידיים (באדג'ים, אריחי קישורים) הומרו לרכיבים שהצוות יבנה בפועל (אריחי KPI, URL Actions). RTL/עברית — מטופל על ידי הצוות (measures ואמצעים).

## מנגנון מסך מוסתר
לשונית "תיק יישוב" מוסתרת כברירת מחדל ואינה מופיעה בשורת הלשוניות. פקד דיסקרטי בתחתית העמוד ("⋯ הצג מסך מוסתר") חושף אותה בעת הצורך ומעביר אליה; לחיצה חוזרת מסתירה בחזרה. הפקד בתחתית כדי שהלקוח לא ייתקל בו בראש המסך בזמן ההצגה. הכול נשאר בקובץ אחד.

## פתוח · השלבים הבאים
- להשיג חשבון API לגיידסטאר, לחיבור דגלי הכשירות (ניהול תקין, סעיף 46, תמיכות/שירותים, גירעון).
- לצבור snapshots שנתיים כדי לבנות את סדרת ההכנסות הרב-שנתית.
- לשקול פענוח דוחות כספיים (PDF) אם רוצים פילוח הכנסות מלא.
- לחבר את מקורות הנתונים ל־dataset אחד (ETL) — התמיכות שלנו, אוכלוסיית למ"ס, שדות רשם העמותות/גיידסטאר, ומערכת ה־SLA.
- להחיל את אותו אודיט היתכנות על יתר הלשוניות (למשל SLA) לפי הצורך.

## מקורות רשמיים שנבדקו
- מאגר רשם העמותות הפתוח — `data.gov.il` (dataset: moj-amutot, משרד המשפטים).
- גיידסטאר — Organizations API v1.4 (משרד המשפטים; דורש חשבון).
- עמוד הארגון בגיידסטאר — SPA ב-JS, לא לגרידה; משתמשים ב-API בלבד.
