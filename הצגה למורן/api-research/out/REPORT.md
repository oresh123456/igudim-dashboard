# מקורות API ציבוריים לשדרוג דשבורד מורן — דוח ממצאים

מקור: research-swarm, 20 תחומי חיפוש, 340 מקורות נגזרו, 1,612 ממצאים, 159 מקורות/רעיונות ייחודיים.
עדשת עדיפות: **דאטה מרחבי (spatial) + הצלבה יצירתית** של רשומות המשרד עם מקורות חיצוניים.
כל מקור נבדק מול תיעוד רשמי; דגלי אמינות ו-ToS מסומנים.

---

## 0. המהלך המרכזי — "שרשרת ההעשרה המרחבית"
הרעיון היצירתי החזק ביותר שעלה, שמחבר הכול:

```
רשומת ארגון/אגודה פנימית (שם, כתובת חלקית, תקציב)
   │
   ├─(א) מפתח ישות: מס' עמותה/ח"פ  ──►  moj-amutot + BudgetKey + GuideStar
   │        └─ פיננסים, ניהול תקין, סעיף 46, תמיכות כל-משרדי (תלות בתמיכה אמיתית)
   │
   ├─(ב) גאוקוד כתובת  ──►  GovMap (רשמי) / Google / BudgetKey entities_geo (מוכן!)
   │        └─ lat/lng מדויק
   │
   └─(ג) הצלבה מרחבית של ה-lat/lng:
            ├─ dataset 408 (מתקני ספורט, כבר עם נ"צ) → מתקן קרוב, צפיפות
            ├─ CBS אזורים סטטיסטיים → אוכלוסייה + מדד חברתי-כלכלי (equity)
            ├─ גבולות רשות (משרד הפנים) → point-in-polygon לאימות "רשות מקומית"
            └─ איזוכרונים (TravelTime) → נגישות תח"צ לאוכלוסייה (מדד impact)
```
**הזהב:** `BudgetKey.entities_geo` — 533,291 ישויות ישראליות **כבר מגאוקודות** (lat/lng), ממופתחות ב-entity_id = מס' עמותה/ח"פ. join אחד = קואורדינטות לכל ארגון נתמך, בלי להריץ גאוקודר בעצמנו.

## Tier 2 — חזק, מומלץ (רשמי/מבוסס, השלמה נדרשת)

**גבולות ומרחב (לבסיס המפה/heat maps):**
- **גבולות שיפוט — משרד הפנים** (ArcGIS Open Data): פוליגוני רשויות **סטטוטוריים** — הכי סמכותי ל-choropleth ול-point-in-polygon לאימות שם רשות.
- **CBS אזורים סטטיסטיים 2022** (SHP/GeoJSON): 3,857 פוליגונים תת-עירוניים → join ל-אוכלוסייה + מדד חברתי-כלכלי.
- **CBS מדד חברתי-כלכלי** (אשכול 1-10 לפי יישוב/אזור): עדשת equity לטאב impact. עדכון איטי (~2021). גם כשכבת GovMap (lay=218044) לשליפה נקודתית.
- **citiesandsettelments / שמות יישובים** (data.gov.il): טבלת **סמל יישוב** — החוליה שמחברת שם-עיר חופשי ל-geography המקודדת של CBS.

**ארגון/פיננסי (כרטיס "גוף נתמך"):**
- **GuideStar Israel** — אין API! רק אתר. אבל שדות עשירים (סעיף 46, תמיכות-לפי-שנה, בעלי תפקידים, 5 שכירים בכירים) שאין ב-moj-amutot. מהלך: בקשת דאטה בין-משרדית (info@guidestar.org.il) במקום גרידה.
- **tmichot.mof.gov.il** — מקור-אמת רשמי לתמיכות ממשלה (לאימות BudgetKey). אין export מובנה.
- **CBS Time-Series API (SDMX)** — אוכלוסייה לפי יישוב/גיל/מגדר לרענון אוטומטי של מכנה ה-per-capita.

**גאוקודינג חלופי/גיבוי:**
- **Google Geocoding** ($5/1000, 10K חינם/חודש) — איכות טובה, אך **אזהרת ToS חמורה** (ר' סעיף אזהרות).
- **Photon (komoot)** — חינם, **עבד מול עברית** כשה-Nominatim הציבורי חסם אותנו. גיבוי מעשי.
- **Geofabrik Israel extract** (.pbf יומי) — self-host offline, עוקף כל rate-limit של Overpass/Nominatim לצינור production.

## Tier 3 — סיטואציוני / יצירתי (הזדמנות, לא ליבה)

**נגישות מרחבית (מדד equity חדש, עדשת העדיפות):**
- **TravelTime Isochrone API** — **כיסוי ישראל מלא מאומת** לתח"צ/הליכה/רכב. "כמה אוכלוסייה בטווח 30 דק' תח"צ ממתקן" — מדד impact חדש ואמיתי. commercial, לבדוק ToS על אחסון פוליגונים.
- **Open Bus Stride API (Hasadna)** — GTFS ישראלי RESTי, /gtfs_stops עם נ"צ → מרחק-למתחנה-קרובה לכל מתקן.
- **OpenRouteService** — איזוכרוני הליכה חינם (500/יום), משלים ל-TravelTime.

**הישגיות (טאב ביצועים ומגדר):**
- **Wikidata SPARQL** — מדליסטים ישראלים + עיר-אירוח (P625) למפת "הישגים בעולם"; מועדונים/אצטדיונים עם נ"צ. חינם CC0. רעש בקטגוריות רחבות → סינון bounding-box.
- **Olympedia / Kaggle "120 Years"** — היסטוריית מדליות ISR מלאה + פילוח מגדרי, one-time.
- **IJF Judobase** — ג'ודו = ענף המדליות #1 של ישראל; דירוגי-עולם חיים (unofficial endpoint).

**אות-חיוניות דיגיטלי (הרעיון היצירתי של "נוכחות רשת כפרוקסי"):**
- **Google Places (New)** — text-search לשם מועדון → נ"צ + **rating + review count** (פרוקסי למעורבות ציבורית) + אתר, בשאילתה אחת. משלב את עדשת המרחב ואות-החיוניות יחד.
- **Google Knowledge Graph / Wikidata P856/P2013/P2003** — אתר + הנדלים חברתיים; "גוגל מכיר את הארגון?" = baseline דיגיטלי.
- **Facebook/Instagram Graph API** — follower count כ-"vitality score". אך **שער App-Review כבד** (שבועות) — לא set-and-forget.

**סביבתי (outdoor/water sports, עדיפות נמוכה):**
- **IMS Envista API** — מזג אוויר רשמי, ~85 תחנות עם נ"צ; מפתח ידני. Open-Meteo כ-fallback ללא מפתח.
- **מי רחצה (משרד הבריאות)** — איכות מים לחופים למועדוני שיט/שחייה. רק מפה/PDF.

**כלי ויזואליזציה (ל-QuickSight):**
- **QuickSight native Layer Maps** — choropleth מ-GeoJSON (פוליגונים בלבד, לא נקודות).
- **Leaflet + CARTO Positron** (חינם) / **deck.gl** — עבור heat maps צפופים דרך custom-visual iframe (X-Frame-Options נדרש).

## ⚠️ אזהרות מהותיות (לפני מימוש)

1. **Google Geocoding ToS** — lat/lng ניתן ל-cache **רק 30 יום**, או לצמיתות רק ל-app מול משתמש-קצה עם בידוד per-user. **טבלת נ"צ פנימית קבועה ב-DWH לא מותרת ברור** — ייעוץ משפטי. (place_id כן ניתן לאחסון לצמיתות.) → העדיפו **GovMap** (רשמי) או **entities_geo** (open data מגואוקד) לטבלה קבועה.
2. **GovMap token domain-locked** — מיועד ל-embed בדפדפן, לא ל-ETL שרת. לבדוק REST/headless לפני צינור batch.
3. **Nominatim ציבורי חוסם datacenter IPs** (403 אצלנו) + 1 req/sec + חובת caching. ל-production: self-host או Photon.
4. **רעננות** — dataset 408 (~2021), CBS מדד (~2021), igudim_2024 (סטטי) — לבדוק גרסה עדכנית לפני שימוש כ"חי".
5. **BudgetKey/Stride = civic-tech (Hasadna)**, לא מקור ממשלתי ראשי — להצליב מול tmichot.mof.gov.il / רשומות פנימיות לפני דיווח רשמי.
6. **תקציב לוטו/טוטו ("זוכה לקהילה")** — לא מפורסם מובנה. טריק: לסנן ב-dataset 408 שמות "פיס"/"טוטו" (62+ hits) כפרוקסי למימון הגרלה.
