# דשבורד איגודים ואגודות

דשבורד אינטראקטיבי לתצוגת נתוני איגודים, אגודות, ספורטאים וספורט נשים — מבוסס על מבנה ה-STT של אגף הספורט במשרד התרבות והספורט.

## הערה חשובה

**כל הנתונים בדשבורד הם פיקטיביים ונועדו לצורכי הדגמה בלבד.** הנתונים אינם משקפים מצב אמיתי של איגודים, אגודות או ספורטאים.

## מבנה הקבצים

- `index.html` — עמוד כניסה (login), שער הסיסמה לדשבורד
- `dashboard.html` — הדשבורד עצמו, נטען רק אחרי כניסה תקפה
- `data.js` — שכבת הנתונים (פיקטיבית), נטענת אוטומטית על-ידי `dashboard.html`

## גישה

הגישה לדשבורד מוגבלת בסיסמה. הסיסמה מוחלפת ב-hash (SHA-256) בתוך `index.html` — לא נשמרת במלל גלוי בקוד. אחרי כניסה תקפה נשמר דגל ב-`sessionStorage` שמאפשר ניווט בדשבורד עד סגירת הדפדפן.

הערה: זוהי הגנה ברמת הלקוח, מתאימה לחומר הדגמה לא-רגיש. לכל מי שמקבל את כתובת ה-URL ואת הסיסמה תהיה גישה מלאה.

## הרצה מקומית

פתחו את `index.html` בדפדפן. כל התלויות (Chart.js, פונט Heebo) נטענות מ-CDN.

## פרסום ב-GitHub Pages

הקבצים מוכנים ל-deploy ישיר. דחפו את `index.html`, `dashboard.html`, ו-`data.js` ל-repo, ואז הפעילו GitHub Pages מהענף הראשי (Settings → Pages → Source: main → /).
