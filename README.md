# דשבורד איגודים ואגודות

דשבורד אינטראקטיבי לתצוגת נתוני איגודים, אגודות, ספורטאיות וספורט נשים — מבוסס על מבנה ה-STT של אגף הספורט במשרד התרבות והספורט.

## הערה חשובה

**כל הנתונים בדשבורד הם פיקטיביים ונועדו לצורכי הדגמה בלבד.** הנתונים אינם משקפים מצב אמיתי של איגודים, אגודות או ספורטאים.

## מבנה הקבצים

- `index.html` — הדשבורד הראשי
- `data.js` — שכבת הנתונים (פיקטיבית), נטענת אוטומטית על-ידי `index.html`

## הרצה מקומית

פתחו את `index.html` בדפדפן. כל התלויות (Chart.js, פונט Heebo) נטענות מ-CDN.

## פרסום ב-GitHub Pages

ראו את `DEPLOY.md` למדריך מלא.
